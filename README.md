# D2L-PyTorch-Study
深圳大学 计算机科学与技术卓越班 | 大二开学前暑假深度学习自学仓库
## 仓库简介
本仓库用于记录李沐《动手学深度学习(Dive into Deep Learning)》PyTorch全套手写练习代码，承接numpy-pandas数据分析基础，夯实深度学习理论与模型实现能力，为后续大模型学习、微调、RAG项目搭建底层技术栈。每日更新章节练习代码，完整记录自学过程，用于保研实验室面试履历展示。

## 当前目录文件说明
- day01_数据操作实现.py：PyTorch张量基础创建、运算、切片操作
- day02_数据预处理.py：数据集加载、缺失值处理、数据归一化
- day03_线性代数.py：矩阵运算、向量操作、线性变换基础实现

## 每日更新规则
1. 每章学习完成后新增对应章节文件，同步更新本README目录清单
2. 提交备注格式：`章节名称 + 当日学习知识点总结`
3. 仅上传手写练习代码，无直接复制课程源码，全部自主调试实操练习

## 学习路线规划
1. 阶段1：深度学习基础理论：线性网络、MLP、训练优化策略
2. 阶段2：卷积神经网络：经典CNN模型复现，计算机视觉基础
3. 阶段3：序列模型与注意力机制：RNN、LSTM、多头注意力、Transformer
4. 阶段4：大模型前置拓展：预训练模型原理、LoRA微调、检索增强生成基础
